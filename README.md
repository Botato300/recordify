# Recordify
A web application for recording the device's screen from the browser, using the browser's API.

> [!NOTE]
> It only works in some modern browsers. See the [compatibility chart](https://developer.mozilla.org/en-US/docs/Web/API/Screen_Capture_API#browser_compatibility).

## How to run
You need to have **NodeJS** and **pnpm** installed. To run the website, simply execute the following commands in your terminal:

1. Install dependencies:
```bash 
pnpm install --frozen-lockfile
```

2. Run the website:
```bash
pnpm dev
```
